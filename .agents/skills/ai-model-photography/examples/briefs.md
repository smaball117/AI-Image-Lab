# 从一句话到高清真实 AI 模特生图提示词：3个示例

**全部为文字输入，不需要任何参考图片。** 这些是用于测试的原创示例，不是声称模型已按提示词实际出图。

## 例1：白色耳机商业模特

**用户原句：**
> 一个年轻漂亮的欧美女孩，戴着白色耳机，皮肤细腻，光线柔和，自然站立，真实一点，高清。

**按文章方法拆解：**

| 原词 | 具体改写 |
| --- | --- |
| 年轻漂亮 | 约20岁成年女性，柔和椭圆脸，深棕眼睛，深金棕色发丝自然束起，清爽自信的表情 |
| 皮肤细腻 | 细小肤理、鼻翼细微毛孔、自然肤色差异与克制高光，避免蜡像磨皮 |
| 光线柔和 | 左前上方大面积柔光，鼻梁颧骨柔和高光，另一侧自然渐变阴影 |
| 自然站立 | 一脚轻微承重，肩部放松，头部轻微侧转，指尖自然接触耳罩 |
| 真实一点 | 耳罩与发丝、耳部的接触合理，衣服柔软自然、有受力褶皱 |
| 高清 | 中长焦人像透视，眼睛与白色耳机同时清晰，发丝皮肤与耳机轮廓保留细节 |

**优化后可生图提示词：**

> 高端清爽的消费电子商业人像摄影，一位约20岁的成年女性模特佩戴一副白色头戴式耳机。模特拥有柔和椭圆脸、自然的面部轮廓和深棕色眼睛，深金棕色发丝梳理整齐并自然束起，留有少量细碎发丝，但不遮挡耳罩与头梁。面部神情自信松弛，嘴角轻微放松，视线朝向镜头。皮肤呈现与年龄相符的细微真实肤理、轻微自然肤色差异与克制的皮肤光泽，拒绝塑料磨皮。身体自然站立，一侧腿轻微承重，肩颈放松，头部略微转向耳机一侧，一只手指轻触耳罩边缘，手指关节和接触位置正确。身穿无图案浅灰色柔软上衣，衣料在肩肘处出现少量自然褶皱。采用简洁浅灰背景、胸像到半身的商业肖像构图，中长焦人像透视，面部比例自然；白色耳机、人物双眼和手指与耳罩接触处构成明确视觉焦点。左前上方大面积柔光塑造面部轮廓，颧骨、鼻梁与耳机外壳有柔和高光，另一侧脸颊形成平缓渐变阴影。目标为高分辨率写实商业照片，发丝、肤理、耳机表面材质和边缘清楚而不过度锐化，背景层次柔和虚化；避免蜡像皮肤、光线平均无层次、表情僵硬、耳机被头发遮挡、耳机变形、手指畸形、噪点与AI涂抹。

**说明**：原句没有指定发色、背景和上衣，因此此例为补全一幅完整画面所做的**可替换设计选择**，不是声称用户已指定这些信息。用户若给出明确细节，保留用户细节。

## 例2：童装模特

**用户原句：**
> 12岁男童穿纯棉家居服，坐沙发，动作自然，衣服有质感，人物高清真实。

**维度拆解**：年龄锁定12岁；肤理按儿童年龄选择；坐姿明确承托；纯棉衣服体现组织、褶皱与走线；镜头既要看人也要看衣服；清晰的是脸、领口、印花和服装。

**可生图提示词：**

> 写实童装电商商业摄影，一名12岁男童穿着纯棉家居服自然坐在简洁浅米色沙发上，保留真实稚气与自然的脸部比例，神情放松，双眼明亮。皮肤细腻但保留符合年龄的轻微自然肌理和肤色层次，没有成人化细纹或蜡像磨皮。臀部由沙发坐垫稳固承托，后背自然挺直略靠椅背，肩部放松，双手自然搭在腿上，腿部位置与座面支撑合理。家居服呈现纯棉细致的真实织物组织、自然垂坠和坐姿引起的腰肘褶皱，领口、袖口与缝线清晰；不添加用户未提及的罗纹、品牌和图案。以略高于坐姿视线的中景取景，人物与服装正面占主要画面，镜头透视自然，脸部和服装关键工艺清楚对焦。左前上方柔和窗光使面部与衣料受光连贯，暗部有轻柔层次，沙发与人物接触处阴影自然。目标高分辨率真实商业照片，发丝、面料与服装边缘清晰而不过度锐化，避免僵硬坐姿、悬浮、衣服变形、皮肤塑料感和低质量涂抹。

## 例3：商务耳机

**用户原句：**
> 商务降噪耳机，成熟男模特，高级冷感，光影立体，高清。

**维度拆解**：产品定位决定成人人设与克制表情；“冷感”用颜色、背景和明暗表达；“高清”要保证耳机、侧脸轮廓与眼部可辨。

**可生图提示词：**

> 极简商务数码广告摄影，一名约30岁的成年男性模特佩戴黑色头戴式商务降噪耳机，面部轮廓清晰，短发整洁，目光专注冷静，嘴唇自然闭合，穿无图案深灰色轻质外套。人物肩部放松、身体略侧，头部微转，使耳罩侧面轮廓和头梁结构清楚可见，头发不遮挡耳机。肤色自然，面部保留轻微真实肤理，不做塑料磨皮。采用低饱和冷灰背景，半身侧前方取景，中长焦透视，耳机与侧脸、眼睛均清晰可读。左前侧方向性柔光形成明确的明暗关系，鼻梁、颧骨与耳机边框出现克制高光，右侧脸颊渐暗，暗部保留必要细节。目标高清商业摄影质感，耳罩接缝、表面材质、发丝与皮肤细节干净锐利，避免耳机结构失真、面部扁平、过度锐化、僵硬姿态和失焦。

## 用例边界

以上都直接面向**新生成的高分辨率人物照片**，不是“高清修复参考图”。如用户明确要求只优化一句话里的某一个模糊词，则按该词输出变量，不必强行生成完整照片方案。
