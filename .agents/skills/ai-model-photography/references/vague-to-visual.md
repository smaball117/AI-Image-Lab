# 模糊提示词转译为可执行视觉变量

**按原文六大问题组织。核心是将抽象形容词转换为生成图像时能被看见、检查的画面特征。**

## 1. “漂亮” → 人物特征与产品定位

- 年龄段：儿童、青少年、年轻成人、成熟成人（根据产品定位）。
- 脸型：柔和鹅蛋脸、椭圆脸、方脸、轮廓流畅等；与气质而非绝对美丑挂钩。
- 面部骨相：颧骨/下颌线/额头的自然形态。
- 发型：短发/长发、发丝方向、层次、束发方式。
- 眉眼与唇：眉形、眼形/眼神、虹膜颜色、唇形及表情。
- 产品匹配：年轻休闲耳机偏轻快，商务降噪耳机偏成熟理性，运动产品偏活力，珠宝可偏时尚克制。年龄仅是可选范围，不要把定位硬性等同于某种美貌。

**示例（仅作为可选设计方向）**：把“年轻漂亮的女性模特”转为“约20岁成年女性，柔和椭圆脸，五官线条清晰，黑棕色长发自然梳理，深棕色眼睛，神态清爽自信”。没有参考图也能生成。

## 2. “皮肤细腻 / 真实” → 皮肤真实感

- 需要：自然且不过度均匀的肤理、与年龄相符的细微毛孔、微小色差、自然皮肤光泽；光照条件适当时可见细发/绒毛。
- 成人成熟肤质：在适合时保留轻微眼下/嘴角纹路。
- 青少年/儿童肤质：细致毛孔和轻微自然肤色差异即可；不强加成人皱纹、明显雀斑或夸张瑕疵。
- 运动场景：可使用轻微真实汗意，不能把所有肤质统一写为油亮。
- 禁止：统一光滑到像蜡、磨皮涂抹、机械规则点阵毛孔。

**示例**：“面部保留年龄相符的细微皮肤组织与自然色彩变化，鼻翼和两颊的微观纹理真实但克制，高光柔和，无塑料磨皮感。”

## 3. “光线柔和 / 高级” → 方向、光质、明暗、高光、阴影

拆解四项：**光源位置**（左/右/前/后/上）、**明暗关系**（低/中/高反差，必要时辅以光比）、**高光落点**（鼻梁、颧骨、产品边缘等）、**阴影形态与过渡**（软硬、暗部层次）。

条件分支：
- 温柔、清透：侧前方大面积漫射主光，面部高光克制，反侧有轻柔渐变阴影。
- 高冷、利落：明确侧光和较强明暗层次，强调面部/产品轮廓。
- 活力明快：明亮的偏正面柔光，保留轻微立体阴影而非绝对平光。
- 午后松弛：低角度窗光或柔和侧逆光，发丝和衣料边缘可有暖色轮廓。
- 剪影特例：暗部可以深黑以服务概念，不能机械套用“暗部必须通透”。

**示例**：“左前上方大面积柔光照亮面部，鼻梁与颧骨呈柔和高光，右侧脸颊产生平缓渐变阴影，暗部保留五官层次。”

文章给出 1:1.5、1:2、1:3 等写法作为*示意*。文本模型可能将其识别为风格提示，不代表实际生成器按摄影测光公式精算。

## 4. “自然站立 / 坐着 / 走路” → 具体身体信号

- 站姿：脚部承重、肩膀、骨盆、头部轻微方向、下巴、视线、手指。
- 行走：一脚承重，另一脚迈步，手臂顺步态反向摆动，衣服出现受力动态褶皱。
- 坐姿：坐面支撑、背部/靠背接触、腿部落点、上肢摆放、衣摆与座面接触。
- 手持产品：手指贴合真实物件，产品朝向与关注点协调，不遮住核心结构。
- 眼神与情绪：视线目标、嘴角轻微变化，不必人人“极淡笑意”。

**示例**：“身体重心微向左腿倾斜，肩膀自然放松，头部轻微侧转，右手轻触耳机耳罩，手指弯曲合理，目光平和地望向镜头。”

## 5. “服装有质感” → 面料、垂坠、褶皱和真实受光

- 服装品类、颜色、衣领/袖口/下摆结构。
- 实际材质：纯棉平针、织物、羊毛针织等，用户已明确则严格保持；**不知道就不要强制指定罗纹**。
- 自然穿着：肩部、肘部、腰部/坐姿处的受力褶皱与身体贴合。
- 受光：织物纤维与表面反射一致；不能塑料化或失去厚度。

**示例**：“米白色棉质上衣，面料细致柔软，肩线与袖口工艺清晰，肘部随动作产生轻微自然褶皱，保留布料纤维质感。”

## 6. “高清 / 8K” → 生成结果的摄影表达与细节标准

关键区分：这里的“高清”指**目标生成照片**，**不是要输入参考图、修复旧图或放大现有图像**。

- 分辨率目标：用户若指定具体像素/4K/8K，可传给支持该设置的生成工具；文字提示本身不改变模型实际输出尺寸。
- 焦段意图：人像近景常用中长焦效果，环境人物可用标准/较广视角，避免错误脸部透视。
- 光圈/景深意图：按主体选择浅景深或中等景深；不要使重点商品失焦。
- 焦点：人像眼睛、戴耳机的人像眼睛及耳机、服装的关键工艺等。
- 细节标准：睫毛、发丝、真实肤理、衣料纤维、产品轮廓清晰；边缘不涂抹、不白边、不锐化过度。
- 禁止项：不必要的运动模糊、失焦、噪点、涂抹、边缘伪影。

**示例**：“高分辨率写实商业人像摄影，标准到中长焦透视，双眼与白色耳机清晰对焦，皮肤纹理和发丝细节自然锐利，背景层次柔和虚化，避免噪点、失焦与过度锐化。”

## 组合规则

不要仅把以上词汇拼接成长清单。按目标产品确定视觉焦点，再选择匹配的人物、姿态、镜头和光影；最终同时说明“要什么”和针对性“不要什么”。**生成目标高清**与**上传图修复**严格区分。
