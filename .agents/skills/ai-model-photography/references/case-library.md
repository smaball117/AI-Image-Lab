# AI 模特提示词案例库：从简略文字到完整生图指令

**工作方式**：用户提供一句话或初稿，Skill 自动细化人物、皮肤、光影、姿态、服装、镜头和目标画质，不需要上传参考图。

以下结构来自用户提供的文章《AIGC— AI模特的真实感如何做到》的分析角度。示例和具体措辞经重新编写，避免把文章里的完整长提示词当成固定模板。各场景均是文本设计案例，尚未标记为模型实测通过。

## A. 产品定位决定人物描述

| 使用场景 | 人物的可选具体变量 | 视觉焦点 |
| --- | --- | --- |
| 青年休闲耳机 | 18-22岁年轻模特；轻快自然发型、亲和眼神 | 佩戴方式、耳罩轮廓、耳机与耳部 |
| 商务降噪耳机 | 25-35岁成年模特；克制发型、专注表情 | 头戴结构、商务氛围 |
| 运动耳机 | 成年运动人物；精神饱满、步态轻快、自然汗感可选 | 耳机佩戴稳定与身体动作 |
| 时尚饰品 | 成年的时尚模特；脸型、发型应衬托饰品 | 饰品轮廓、反射和脸部比例 |
| 童装电商 | 年龄匹配的童模、自然童真表情，站坐姿合理 | 服装的颜色、领口、印花、版型 |

年龄/发型/脸型只在用户尚未指定时作为**设计候选**；如果用户已指定，必须保留。不要把某种面容等同于绝对“高级”。

## B. “皮肤细腻”有不同落地方式

- 青少年：细微毛孔与自然肤色层次，皮肤干净但不蜡化；不额外添加成人皱纹。
- 成年美妆：细小肌理、妆感、鼻翼和唇周细节、面部绒毛根据光照可见。
- 成熟人物：必要时保留符合年龄的眼下或嘴角纹理，不采用一键美颜脸。
- 运动：运动后自然汗光与皮肤纹理并存，不能把油光当成真实感。
- 暗调剪影：皮肤未必需要明显毛孔，重点是轮廓受光、五官起伏与局部反射。

## C. “柔光”不是一种固定布光

| 情绪与画面 | 可选具体光影 |
| --- | --- |
| 温和治愈 | 窗户漫射光、低到中等明暗反差、柔和渐变阴影 |
| 清冷时尚 | 明确的侧光、偏冷色高光、背景压低明度 |
| 明亮活泼 | 正前上方大面积柔光、眼神光、面部保留轻微立体阴影 |
| 安静沉浸 | 单一方向局部光、注意力聚焦在脸或产品 |
| 午后松弛 | 较低角度侧光或侧逆光、适度暖色轮廓 |
| 黑色剪影 | 主体暗面可以几乎不见，只保留轮廓光，禁止额外正面平光 |

每种都写：光源方向 + 形态 + 高光部位 + 阴影/暗部。数值光比是可选提示线索，不是必须固定为1:2。

## D. “自然”依动作而变

| 动作类型 | 重心/支撑 | 小动作/接触 |
| --- | --- | --- |
| 站立 | 一侧腿轻微承重、肩颈放松 | 轻转头部、手指弯曲、视线确定 |
| 行走抓拍 | 前后脚有明确承重相位 | 手臂反向摆动、发丝与衣摆轻微惯性 |
| 坐姿 | 臀部确实坐稳、后背受托或自然直立 | 手搭扶手或腿部、坐垫受压、褶皱真实 |
| 拿产品 | 上肢与肩肘手腕连续合理 | 指尖接触产品实际部件，不挡重要细节 |

## E. “高清”要与场景焦点匹配

| 场景 | 焦段/景深意图 | 优先对焦 |
| --- | --- | --- |
| 人像特写 | 中长焦、较浅景深 | 双眼、睫毛、发丝，肌理自然 |
| 佩戴耳机的肖像 | 中长焦、产品与眼部处于可读清晰范围 | 双眼与耳机结构 |
| 户外走路 | 稍广的环境人像视角、中等景深 | 人物面部、服装展示 |
| 童装上半身 | 标准到中长焦、适度景深 | 面部与服装工艺/印花 |
| 手持产品 | 近景、充足景深 | 手指、产品接触部位、品牌文字如有 |
| 暗调剪影 | 焦点落在轮廓与核心饰物 | 轮廓光、产品反射，不强行提亮脸 |

可以指定目标 4K/8K 风格或目标像素，但真正的文件分辨率由所用生成模型、配置与后处理决定，不能仅凭“8K”三个字符保证。

## F. 一句模糊话的完整拆解示范

**初稿**：“年轻漂亮的欧美女孩戴白色耳机，皮肤细腻，光线柔和，自然站立，真实一点，高清。”

分解：
1. 漂亮 -> 选适合青年耳机广告的成年年轻女性，明确脸型、发型、眼神和唇形。
2. 细腻 -> 细小肌理、自然色差与高光，非塑料磨皮。
3. 柔和 -> 明确柔光来自哪里，哪些脸部有高光，阴影如何过渡。
4. 自然 -> 站姿重心、肩线、头颈、手指、视线。
5. 真实 -> 耳机佩戴、头发与耳罩遮挡关系、服装褶皱、光影连续。
6. 高清 -> 景别、焦段意图、景深、双眼与耳机对焦、微细节、避免噪点和涂抹。

**完整成图提示词见** `examples/briefs.md`。

## 用长案例学习“变量”，不照搬“画面”

原文章也包含橙黑剪影系列、美妆换色变体、白背景眼镜人像等。其可迁移的不是固定橙色、某种眼镜、某个年龄，而是“多场景中把人物、材质、光线、姿态、构图按需要组合起来”的方法。

一条输入词只有“高清”时，也可先只补焦段、对焦与清晰的部位；用户明确要求全套商业模特提示词时，应完整覆盖六个维度。
