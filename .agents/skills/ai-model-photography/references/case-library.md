# 案例库：从文章中提炼的“优化模式”，非现成生图模板

来源：用户提供的站酷文章《AIGC— AI模特的真实感如何做到》（口木文化x何柳健，2026-09-11）。
此处是**概念提炼、简写及新写练习题**，并非复制文章全部长提示词，也不声称已验证生图结果。用场景案例帮助识别如何改写用户的原提示词。

## 文章案例与可复用的诊断角度

| 文章场景 | 原文主要强调的变量 | 优化时学到什么 | 不应照搬的部分 |
| --- | --- | --- | --- |
| 白色耳机 + 年轻人物 | 年龄、产品定位、外貌具体特征 | “漂亮”需转换成定位匹配的具体特征；已有脸参考时保留身份 | 固定长相、年龄、发型 |
| 美妆人物 + 唇釉 | 皮肤纹理、手部与产品的物理关系、光影覆盖面 | “细腻”“柔光”落到可见部位，聚焦真实接触 | 唇釉品牌、特定手势、固定1:2光比 |
| 影棚站姿 / 走路 / 坐姿 | 重心、肩、头、眼神、手指、衣服褶皱 | “自然”应按动作类型分别展开 | 所有人都微笑或重心偏同侧 |
| 特写 / 街拍 / 室内 / 俯拍 | 机位、焦点、主体主次、环境虚化 | “高清”不仅是分辨率，更是该清楚的地方清楚 | 85mm、f/2.8、8K强制套用 |
| 橙黑剪影连续不同姿势 | 人物身份锁定、统一道具服装光线、仅变动作 | 多图系列保持 invariants，只让姿态与画面动线变化 | 橙色、墨镜、耳环当作默认元素 |
| 纯白背景的数码眼镜人物 | 深色肌肤真实层次、镜片透光、握持互动 | 纹理、材质、手指动作要彼此匹配 | 单一肤色或单一商业类型 |
| 一套美妆图换背景与服装色系 | 固定脸、手、产品姿态；解锁指定色彩/服饰 | 对变体做 EDIT 与 LOCK 分离 | 未获授权时擅自改色彩 |
| 暗红背景霓虹剪影 | 主视觉光源、主体暗部、限定色域 | 不能一律禁止死黑：剪影时深黑就是创作意图 | “暗部必须通透”的通用禁令 |

## 练习：同一词在不同场景的不同改法

**模糊：自然**

- 孩子在沙发上：描述臀部承托、手掌放置、服装与坐垫接触。
- 成年人街拍：描述一脚承重、一脚迈出、手臂自然反向摆动。
- 美妆面部特写：描述视线、嘴部肌肉和手指与唇釉的接触。
- 结论：“自然”不是固定“肩膀放松、下巴微收”的永恒口令。

**模糊：高级光影**

- 参考图光影锁定：复用原来光线，不自行加打光装置。
- 纯白美妆：受光均匀但保留五官立体与柔影，不让整个脸变平。
- 剪影：允许暗部几乎不可见，以轮廓和少量材质反射塑造体积。
- 结论：不能把“暗部通透无死黑”作为每张图必写的规则。

**模糊：高清**

- 肤质修复：保留自然肤理，避免涂抹，不改变其他结构。
- 卖衣服：准确呈现面料组织、印花、走线和领口。
- 产品互动：握持细节与产品结构比全身每处锐利更重要。

## 长提示词案例的真正用途

原文许多长案例包括人物、姿态、光影、色彩、场景、构图、反向约束等多个层级。用于优化时，**选取原提示词的对应层级补强，不是把所有层级统统重写**。一段很长的生成指令未必优于针对具体失败的一段短替换句。
