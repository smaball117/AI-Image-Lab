# AI 模特提示词输出前质量检查

## 必须通过的文字检查

1. **保留事实**：年龄、人物地域特征、发型、服装、商品、场景、画幅等用户已给出的内容未被改动。
2. **具体可执行**：把“漂亮、自然、柔和、真实、高清”等模糊描述转成可见的特征、动作、光影或焦点，没有只用同义词堆叠。
3. **镜头与构图**：景别、机位、焦点、主体与商品清晰范围相容；不强制 50% / 70% 等固定百分比。
4. **背景与主次**：背景若未指定，且是商品人像，可选简洁低干扰背景；若已指定具体场景，则保留该场景。
5. **整体质感**：人设/商品定位匹配，光影和产品材质可信，衣服或产品结构不凭空增加。
6. **姿态合理**：站坐行走/握持的重心、手指接触、肩颈连续；商品不被手或头发无意遮挡。
7. **克制肤质**：人物皮肤自然、适龄，不默认长篇毛孔清单或儿童成人皱纹。
8. **简洁可复制**：一个完整中文提示词即可，反向约束少而准确；用户若只要提示词，不输出前置分析。
9. **不超出能力**：明确“高清”是目标成图，不承诺某个文字词就能真的输出8K像素、RAW源文件或保证任何模型一次成功。

## 测试经验如何进入输出

- 来自 Chat 的用户反馈中，**背景简洁**对当前耳机商业肖像表现较有帮助，作为选择性默认。
- 50% vs 70% 主体占比无明显差异；不写死固定占比。
- 皮肤微观细化无明显差异；不强制细抠。
- 持唇釉动作细化无明显差异；重点确保真实握持和产品可见。

**实际生成效果只能由真正的生成器检验**。上述用户反馈是定性、任务特定的观察，不构成跨模型成功率承诺。

## 有问题时的回退

改一项不相关的东西导致画面变差，恢复原本正确的部分，只留下有明确需求支持的修改。不要为了显得专业而扩写无意义的光圈、比例、装饰或否定词。
