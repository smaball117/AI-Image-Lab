# 生图提示词文本质量与结果验收

## 第一层：文字检查（无需图像工具）

对照用户初始输入，判断下列七项（0=不满足、1=部分满足、2=满足）：

1. 主题与产品：人物与商品仍为用户要求，没有擅自换品类。
2. 漂亮->具象：年龄、面部/发型/神态有具体合理描述，产品定位一致。
3. 细腻->肤理：真实的年龄相符细微纹理与针对性避免塑料感。
4. 柔和->布光：有光源方位、适当明暗、高光落点、阴影过渡。
5. 自然->姿态：站、坐、走、拿的动作有重心、接触、肩头手指与视线逻辑。
6. 真实->材质：衣服/耳机/其他商品的材质、褶皱、遮挡、支撑合理。
7. 高清->目标画质：构图镜头、景深、明确对焦目标、发丝皮肤商品边缘细节、针对性排除低清伪影。

满分14分，实验建议>=12且产品/主体不得为0。仅为本 Skill 自定的文本覆盖检查，不代表生成器真实质量。

## 第二层：是否按照用户限制生成

- 用户没上传图，也没有要求上传图：**不得要求参考图，不能默认变成修片工作流。**
- 用户说“高清”：要对最终生成画面的清晰、焦点、镜头、纹理和成品要求负责，而不是“把原图放大”。
- 用户给单句需求：应能补足一套完整可复制的文字生图提示词。
- 用户已确定年龄、服装、产品、背景：保持用户原规定，不随意改动。
- 用户只要求拆解特定词：仅展示拆解，不强制写新场景。
- 允许根据情绪与产品匹配选择镜头、光影、人物细节，并在“为什么这样写”说明哪些是新增选择。

## 第三层：真正生图的 A/B 验证

只有拿原始提示词 A 和改写提示词 B 在同一图片生成器上试验，才能评价实际改善。尽量固定模型、画幅、参考配置（若有）和其他参数，比较：

- 双眼、耳机/服装等视觉焦点是否清楚。
- 皮肤真实感是否改善，而非过度磨皮或人工大毛孔。
- 姿态与手部是否自然。
- 耳机与头发遮挡、服装褶皱、接触/阴影是否合理。
- 光线是否符合指令且有层次。
- 实际输出像素是否达到用户要求（如果工具支持明确设定），不要只看提示词有没有“8K”。

**没有实测图片，就标为“文本检查通过 / 生图效果未验证”。**
