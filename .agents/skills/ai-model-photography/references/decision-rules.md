# 决策规则和失败修正

## 输入路由

| 用户输入 | 应做什么 | 不应做什么 |
| --- | --- | --- |
| 一句话“韩国少女卷发拿唇釉，高级高清” | 读出已知特征，按六维度补足成完整提示词 | 追问参考图/从文章抄陌生角色 |
| 已有长提示词“帮我优化” | 保留全部已锁内容，替换空泛和冲突信息 | 擅自改年龄、发型、商品颜色、环境 |
| “只优化姿态” | 只改姿态/接触部分，其他段落保留 | 全文重新设计光影、服装 |
| “怎么让高清更具体” | 解释焦点、景别、透视、真实边缘与输出设置区别 | 把现有图片当成要放大修复 |
| 场景为沙发/户外/家庭 | 保留场景，消除无关背景干扰 | 一律替换浅灰棚背景 |
| 商品未知包装/品牌 | 使用泛称“唇釉”“头戴耳机”及合理通用材质 | 编造标签、Logo、特殊瓶型 |
| 童装没有具体织法 | 只写实际服装类别与合理面料特征 | 默认罗纹/针织竖线 |

## 六维度逐项判断

1. **人物**：产品是向谁展示？用户指定年龄/韩国人设/卷发等不可变；其余五官可以做克制补足，不替换成另一个类型。
2. **镜头**：产品与人同时是焦点时，优先给两者足够景深并安排相近的物距；如果产品贴镜头而人远离，不能承诺同样清晰。**不要默认85mm + f/2.8**。
3. **光影**：光源应有方向；高光随皮肤、透明管、金属、布料的反射属性变化。若用户要柔和，光源方向明确但阴影过渡柔和；不写互相打架的“无阴影又强轮廓”。
4. **皮肤**：普通成片一句“年龄相符的细腻真实皮肤纹理、自然肤色层次，避免蜡像磨皮”足够；局部脸部特写才用更精细词。
5. **姿态/产品接触**：优先可执行的握持关系，产品完整可读，不挡嘴唇、关键结构、印花等。参考 E05，**无需默认指定哪根手指几度弯曲**。
6. **服装与画质**：真实面料、必要褶皱与服装结构，眼睛和商品应清晰；“8K级”是视觉意图，不能宣称导出分辨率。

## 单点修复优先序

- 背景太乱 → 修改背景复杂度及视觉层级，不改人物/商品。
- 人物太小 → 修改景别和构图词，不指定已被测试未发现差异的万能百分比。
- 产品不清晰 → 明确手与商品相对位置、产品朝向和对焦，必要时适度增加景深。
- 皮肤太塑料 → 使用短的适龄纹理与自然反射词；若细节仍差，交给局部修片，不必无限扩写。
- 手部异常 → 简化动作、确认受力与可见接触；避免同时要求多种手势。
- 光线假 → 明确主光方位、受光表面、阴影过渡；不要简单追加“高级、柔和、RAW”。
- 商品细节不准 → 不编造包装与商标；如用户要求严格产品一致性且只有文字说明，提示文字限制并请求**可选**产品资料，不强迫参考图。

## 输出禁忌

- 不要先输出一整页理论，再将提示词放到最后。
- 不要没有依据地使用固定主体占比、极限浅景深、1:2光比、8K RAW、成人皱纹、绝对无阴影。
- 不要为“真实”盲目添加家具、景物、服装工艺和标签。
- 不要将用户要求的“创建一张新的高清人像”改成“高清放大上传的图片”。
