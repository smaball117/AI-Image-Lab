## 最常用的一句话

```text
$ai-model-photography
18岁韩国少女，卷发，手里拿着一支唇釉。
妆容自然，好看，有高级感，光线柔和，真实高清。
帮我优化成一段能直接拿去生图的完整中文提示词。
```

输出：一版完整、可复制的商业人物摄影提示词，包含人物、镜头构图、光影、皮肤、姿态、产品与服装、画质及必要的禁止项。

默认不需要上传参考图，不执行生图，不修复旧图片。不再强制连续 A/B。
