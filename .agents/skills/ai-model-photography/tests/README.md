# AI 模特提示词优化器 · 封装验收

本 Skill 的研究和 Chat 生图反馈已完成一轮归纳，**不要求用户重新做 A/B 实验，也不要求反复安装多个版本**。

## 目标

用户只说一句模糊描述时，Skill 能保留人设/产品要求，把“漂亮、自然、柔和、真实、高清”翻译成完整、好用、可复制的商业模特生图提示词。

## 结构检查（开发者使用，可选）

```powershell
python scripts/validate_skill.py
python scripts/test_optimization_cases.py
```

脚本只检查文件、内部文档链接和预写测试规格，不调用 Codex 或图片生成器，不代表已达成真实成图质量。

## 安装后只做一次 Codex 烟雾测试

```text
$ai-model-photography
18岁韩国少女，深棕卷发，手里拿一支唇釉，干净自然的妆容，
高级美妆广告，光线柔和，人物真实高清。
请优化成一段完整的、可以复制到 Nano Banana Pro 直接生图的中文提示词。
不用参考图，只需要一版，不要让我做A/B实验。
```

**通过标准**：

1. 能显式调用 `$ai-model-photography`，看到 Skill 被加载/使用的明确行为。
2. 保留18岁、韩国少女、深棕卷发、唇釉与美妆广告；不擅自发明品牌标签。
3. 给一个完整可复制的最终提示词，不要求参考图，不默认生成图片，不把高清理解为原图放大。
4. 具体写出合理的景别/对焦、方向性柔光、自然肤质、手持唇釉、简洁背景、商业质感及必要避免项。
5. 不机械堆毛孔细节、主体百分比、固定f/2.8和1:2光比。

**验收性质**：通过以上只能说明基本的 Codex Skill 调用与输出契约有效。生成器实际成图仍由用户视觉判断，不要称为“稳定出图100%”。

## 其他边界用例（出现问题时才复测）

- **人设锁定**：“12岁男孩穿纯棉家居服坐在沙发，帮我优化高清电商摄影提示词。”不得新增床、成人化妆容、默认罗纹。
- **已有长提示词**：“只改光影，人物、服装和场景原样保留。”不得全文重新设计。
- **纯静物路由排除**：“一支香水的无人物静物摄影。”不应自动调用人物模特 Skill。
- **旧图高清放大路由排除**：“把一张现有JPG放大到4000px。”不应把它改成新的模特拍摄提示词。

## 用户实测结论（详见经验记录）

- E02 简洁背景比未指定背景在耳机广告中更有效（4项均评价 B 更好）。
- E03 人物占画面50%/70%，差不多。
- E04 皮肤细微描述简版/细化版，差不多。
- E05 唇釉持物动作简版/细化版，画面没有明显区别但效果都很好。

**不再把“做更多 A/B”作为每次调用的默认输出。**

## 状态标识

- Static PASS：仅代码/文件完整性、链接与测试规格。
- Codex PASS：必须有真实 Codex 调用输出。
- Image PASS：必须有真实模型生成和用户评价。

未完成的验证一律标记为“未验证”，不允许凭案例示范推断为实测成功。
