# AI 模特提示词优化器 · 研究与封装日志

## 用户 Chat 研究阶段（已完成整理）

| 实验 | 用户反馈 | 封装规则 |
| --- | --- | --- |
| E01 整体明确化 | 完整提示词更聚焦人物，背景干扰较少；正式 A/B 标记未完成 | 确保主体、产品与背景主次清楚 |
| E02 明确简洁背景 | 四项评分全部 B 更好 | 商品广告无既定场景时主动控制背景复杂度 |
| E03 主体占比50/70 | 差不多 | 不固定百分比 |
| E04 皮肤词精细化 | 四项评分都相近 | 默认简短适龄肤质，整体质感更重要 |
| E05 唇釉持物精细化 | 无明显区别，都很好看 | 不强制复杂手指摆位，重点是自然、产品可见 |

**这些是用户在本次 Chat 的定性反馈，没有原始图片的量化测量，也不是多模型统计实验。**
