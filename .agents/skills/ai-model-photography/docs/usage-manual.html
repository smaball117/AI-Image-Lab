BEFORE & AFTER

一句话，到底会被优化成什么？

原始描述 / BEFORE
18岁韩国少女，卷发，手拿一支唇釉。
好看、自然、柔和、高清。

问题：表情、动作、焦点、光线和商品展示都还不够具体。

优化方向 / AFTER

人物：18岁韩国女性，清新自然的少女感，深棕卷发。

镜头：3:4头肩近景，眼睛与唇釉清楚可读。

光影：左前上方大面积柔光，颧骨与唇釉表面有自然高光。

姿态：轻松握持瓶身，产品完整可见，不遮挡双唇。

质感：适龄自然肤质，简洁背景，清晰发丝和产品轮廓。

模糊表达→摄影变量→完整可复制提示词
研究经验：已经观察到“明确控制背景”对于耳机商业肖像的主体突出有帮助；而继续堆毛孔细节、固定主体百分比、复杂手指动作，在本轮 Chat 观察中并没有明显增加收益。
SIX DIMENSIONS

文章里的六个核心转译维度

不是把每个词都无限加长，而是给 AI 一个能被看见、能被判断的画面目标。

01 / APPEARANCE

漂亮 → 人物特征

年龄、脸型、发型、眉眼、唇形与产品定位匹配。

02 / SKIN

细腻 → 自然肤质

符合年龄的真实皮肤层次，避免蜡像磨皮；无需强制写满毛孔清单。

03 / LIGHTING

柔和 → 具体光影

光从哪里来、亮在哪里、阴影怎样过渡。

04 / POSE

自然 → 身体语言

重心、肩颈、眼神、手部与商品接触合理。

05 / REALISM

真实 → 整体协调

服装材质、人体支撑、产品结构、光线与透视协调。

06 / IMAGE QUALITY

高清 → 清晰目标

明确景别、焦点、景深和细节；实际像素由生图工具设置决定。

FAQ

遇到这些情况怎么办？

一定要上传参考图吗？

不用。这个 Skill 默认通过文字优化提示词，只有你主动给参考资料时才使用。

会自动替我生成照片吗？

不会。它输出提示词，你把结果复制到 Nano Banana Pro、即梦等生图工具。

为什么没有一大堆“毛孔、8K、85mm、f/2.8”？

这些不是所有照片必需的固定词。Chat 中皮肤细化与主体50%/70%实验差异不明显；我们把精力集中到整体画面、人物与产品关系。

能不能只帮我改动作，不换原来的人？

可以。在原提示词后加“只优化动作和产品握持，其他全部保持不变”。

童装也适用吗？

适用。明确年龄、衣服材质、展示重点即可；规则会避免不必要的成人化肤质与误加面料工艺。

如果产品要一模一样怎么办？

需要你提供产品真实信息或自行提供参考。没有包装信息时，Skill 只会写通用品类，不会捏造品牌标签。
